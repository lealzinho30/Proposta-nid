# Proposta comercial premium | NID Studio

Material editorial em HTML/CSS para apresentação comercial premium da NID Studio.

## Arquivo principal

- `proposta-nid-studio.html`

## Como usar

1. Abra o arquivo no navegador.
2. Edite os campos entre colchetes, como `[Nome do cliente]`, `[Nome do projeto]`, `[Cidade / UF]` e `R$ [valor]`.
3. Substitua os contatos e o QR code ilustrativo pelos dados oficiais.
4. Para gerar PDF, use a opção **Imprimir > Salvar como PDF** no navegador.

O layout foi preparado para apresentação em formato A4 horizontal, com estética editorial, espaços em branco, imagens conceituais, fluxograma, blocos de escopo, condições comerciais e encerramento institucional.
